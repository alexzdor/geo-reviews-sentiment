
# Geo Reviews Sentiment

Классификация тональности русскоязычных отзывов на организации (негативный / нейтральный / позитивный).
Сравниваются три подхода: **TF-IDF + логистическая регрессия**, **LSTM с нуля на PyTorch** и **дообучение `rubert-tiny2`**.

Главный вопрос проекта: что реально даёт прирост на сильно несбалансированных данных с шумной разметкой: сложная модель, предобучение или правильная работа с дисбалансом?

## Данные

[Geo Reviews 2023](https://huggingface.co/datasets/d0rj/geo-reviews-dataset-2023): около 500 000 отзывов на организации с оценкой 1-5 (зеркало датасета Яндекса на Hugging Face).
Используются колонки `text` и `rating`.

- 200 строк с рейтингом 0 удалены: по прочтению это шум (в большинстве текстов позитив).
- Рейтинг превращён в 3 класса: **1-2 → негатив, 3 → нейтральный, 4-5 → позитив**.
- Итого 499 800 отзывов. Дисбаланс: **9.3% / 4.3% / 86.4%**.
- Разбиение 80/10/10 (399 840 / 49 980 / 49 980) со стратификацией, `random_state=42`. Разбиение делается **до** любой балансировки.
- **Val и test сохраняют естественное распределение классов**, чтобы метрики отражали реальную работу модели.

## Метрика

**macro-F1** (F1 по каждому классу, затем среднее с равными весами). Accuracy здесь бесполезна: модель, всегда отвечающая «позитив», получила бы около 86%.

## Как работали с дисбалансом

1. **Undersampling для обучения.** Из train берётся по 17 349 отзывов каждого класса (размер самого редкого).
2. **Ресэмплинг по эпохам** (LSTM и BERT): в каждой эпохе новая случайная сбалансированная выборка из полного train, так модель за обучение видит почти все данные.
3. **Поправка приора после обучения.** Модель училась при равных долях классов (1/3 каждый), а в реальности их доли другие. Вероятности умножаются на `(реальная доля / обучающая доля) ** alpha`, затем берётся argmax. `alpha=0` значит «без поправки», `alpha=1` значит полная байесовская поправка. `alpha` подбирается **только на val** и фиксируется до взгляда на test.

## Результаты

macro-F1, `alpha` выбран на val для каждой модели отдельно. Test посчитан один раз после фиксации всех настроек.

| Модель | alpha | val | test |
|---|---|---|---|
| TF-IDF (1-2-граммы) + LogReg | 0.5 | 0.699 | 0.7045 |
| LSTM + ресэмплинг по эпохам | 0.5 | 0.688 | 0.6946 |
| rubert-tiny2 + ресэмплинг по эпохам | 0.75 | 0.7258 | 0.7243 |

Эффект поправки приора на val (macro-F1):

| alpha | TF-IDF | LSTM | BERT |
|---|---|---|---|
| 0 (без поправки) | 0.655 | 0.674 | 0.684 |
| 0.5 | 0.699 | 0.686 | 0.717 |
| 0.75 | 0.677 | 0.682 | **0.726** |
| 1.0 | 0.615 | 0.669 | 0.709 |

(Для LSTM приведены цифры первого запуска; при повторном обучении лучший alpha остался 0.5.)

F1 по классам на val при alpha=0.5:

| Класс | TF-IDF | BERT |
|---|---|---|
| негатив | 0.778 | 0.798 |
| нейтральный | 0.354 | 0.393 |
| позитив | 0.965 | 0.961 |

### Настройки моделей

- **TF-IDF:** `ngram_range=(1, 2)`, `min_df=5`, `max_features=200 000`, `sublinear_tf=True`; LogReg, `max_iter=1000`.
- **LSTM:** токены `\w+` в нижнем регистре, словарь 53 439 слов (`min_freq=3`), `max_len=180`, Embedding 128 + LSTM 128 + Dropout 0.3 + Linear, Adam `lr=1e-3`, batch 64, 8 эпох, сохраняются веса лучшей эпохи (early stopping по val macro-F1). Около 7 млн параметров, 98% из них в эмбеддингах.
- **rubert-tiny2** (`cointegrated/rubert-tiny2`, около 29 млн параметров): `max_len=256`, AdamW `lr=2e-5`, `weight_decay=0.01`, batch 32, 3 эпохи.

## Ключевые наблюдения

1. **Дисбаланс определяет всё.** Из-за 86% позитива accuracy вводит в заблуждение, поэтому выбрана macro-F1. Weighted-F1 у baseline был 0.879 при macro-F1 0.655: красивое среднее скрывало провал на нейтральном классе.
2. **Сбалансированное обучение даёт низкую precision редкого класса на реальных данных.** У baseline precision нейтрального класса 0.199 при recall 0.685. Это не баг, а следствие формулы `Precision = TPR·π / (TPR·π + FPR·(1−π))`: при падении доли класса π с 1/3 до 4% precision падает при тех же TPR и FPR.
3. **Поправка приора без переобучения модели** подняла TF-IDF с 0.655 до 0.699 (+0.044). Полная поправка (alpha=1) вредит: она оптимальна для accuracy, но «душит» редкие классы, а macro-F1 требует компромисса. У BERT оптимум сдвинулся к 0.75: предположительно из-за лучше откалиброванных вероятностей (калибровку BERT отдельно не измеряли).
4. **LSTM с нуля переобучается.** Train loss падает до 0.31, а val F1 выходит на плато уже после 4-6 эпох: 6.8 млн параметров эмбеддингов на 52 тысячах отзывов. Ресэмплинг по эпохам помог: лучший val без поправки вырос с 0.621 до 0.670.
5. **LSTM переуверена**: в корзине уверенности 0.8-0.9 точность около 64%. Часть эффекта вызвана сдвигом приоров между обучением и валидацией.
6. **Предобучение даёт реальный прирост.** BERT с поправкой лучше TF-IDF примерно на 0.02 на val и на test, и почти не переобучается (train loss 0.46 к третьей эпохе).
7. **Val и test согласуются** (расхождение не более 0.007), значит выбор эпохи и alpha по val не привёл к заметному переобучению на val.

## Анализ ошибок

Матрица ошибок BERT на val (alpha=0.75), строки это настоящий класс, столбцы предсказанный:

```
              негатив  нейтр.  позитив
негатив         3827     593      224
нейтральный      585    1009      574
позитив          443    1263    41462
```

- Нейтральный класс угадывается хуже всего (47%), ошибки расходятся примерно поровну в обе стороны.
- Самая большая ошибка в абсолютных числах: 1263 настоящих позитива названы нейтральными. Именно они снижают precision нейтрального класса.

Разбор случайной выборки из 20 ошибок на нейтральном классе (настоящая оценка «3 звезды»), прочитанных вручную:

Примеры:

- **Шум метки.** Отзыв «Замечательный мини-отель. Отличные номера. Приветливый персонал. Теперь всегда буду останавливаться здесь» с оценкой 3 и уверенностью модели 0.99 в позитиве. Модель, по-видимому, права, метка спорная.
- **Вежливая тройка.** Отзыв «Было не вкусно. Борщ жидкий, рис сухой... Лучше поискать другой вариант» с оценкой 3: текст негативный.
- **Обоснованная неоднозначность.** «Сам музей прекрасен... Но администраторы очень неприятные люди»: в тексте и плюсы, и минусы, модель выбрала негатив с уверенностью 0.57.
- **Короткий текст.** «Неплохой торговый центр» (модель: позитив, 0.68): информации почти нет, оценка 3, 4 или 5 одинаково правдоподобна. Возможные причины: неразрешимая неоднозначность в данных и ограниченная ёмкость tiny-модели; без эксперимента с моделью побольше различить их нельзя.

Вывод: потолок качества на нейтральном классе ограничен в том числе самой разметкой, а не только моделью.

## Ограничения и что можно улучшить

- **Один запуск на модель.** Разброс между запусками (seed, инициализация, перемешивание) не измерен. Он может быть порядка 0.005-0.01, поэтому разницу TF-IDF и LSTM (около 0.01) нельзя считать значимой; разница BERT и остальных (около 0.02) правдоподобна, но тоже не подтверждена несколькими seed. При повторном обучении LSTM лучшая эпоха сместилась с 4 на 6, что показывает этот разброс.
- **`alpha` и эпоха подобраны на val** (сетка 0, 0.25, 0.5, 0.75, 1.0, грубая). Test использовался один раз для финальной оценки. TODO: если вы смотрели test больше одного раза, честно напишите это здесь.
- **Небольшая модель.** `rubert-tiny2` слаба в тонких градациях («неплохой / хороший / отличный»). Не проверено, поможет ли `rubert-base`.
- **Кросс-энтропия не учитывает порядок классов.** Ошибка «нейтральный → позитив» штрафуется так же, как «негатив → позитив». Возможное улучшение: ordinal regression или предсказание исходных 5 оценок.
- **Шум разметки не очищался.** Можно оценить его долю на большой выборке или применить методы обучения с шумными метками.
- **Обучение на подвыборке за эпоху** (по 17 349 на класс). Альтернатива без выбрасывания данных: веса классов в лоссе. Не сравнивалось.
- **Калибровка** измерена только для LSTM. Для BERT и после поправки приора не измерена.
